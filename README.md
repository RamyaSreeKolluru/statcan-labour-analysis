# statcan-labour-analysis# US Labour Market Analysis (1967-2015)

## Overview
An exploratory analysis of US labour market trends using the `economics` 
dataset from the tidyverse package in R.

## Key Questions
- How has US unemployment changed over time?
- What is the long-run trend in personal savings rates?
- Is there a relationship between unemployment and savings behaviour?

## Key Findings
- US unemployment peaked during the 2008 financial crisis, exceeding all 
  previous post-war highs
- Personal savings rates declined steadily from ~10% in the 1970s to near 
  0% by 2005
- A negative relationship exists between unemployment and savings rates, 
  suggesting sustained joblessness depletes household savings
